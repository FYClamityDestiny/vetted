Vetted privacy policy

Last updated: 14 November 2026

Vetted is a Claude Code plugin that runs on your own machine. It has no accounts, no servers of its own, and no telemetry.

What Vetted does with data

  • Search terms and package names are sent only to the public registries you ask it to search (GitHub, Hugging Face, npm, PyPI, Docker Hub, Open VSX, MCP registries, the Roblox Creator Store, and OSV).
  • Downloaded files are scanned locally. File contents are never uploaded anywhere.
  • Results are cached on your machine in ~/.cache/vetted. Delete that folder at any time.
  • Vetted does not read your tokens, keys or credentials.

Shared ratings

If you choose to share a rating, it is submitted as a public GitHub pull request under your GitHub account. Nothing is shared unless you run the share command and confirm.
