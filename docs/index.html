Vetted is a Claude Code plugin. Tell it what you need. It searches eight sources, scans the best matches for malware without running them, and installs the one you pick, pinned to the exact version it checked.

# in Claude Code
/vetted:find a self-hosted newsletter tool with a Docker image

Three commands

/vetted:find

Describe what you need. Get 3–5 scanned options, a recommendation, and a pinned install after you say yes.

/vetted:report

Fact sheet on one tool or many: author, license in plain words, activity, contents, install command, safety rating.

/vetted:digest

What's new in your interests, plus updates to what you already installed. Run it weekly on a schedule.

How the check works

  1. Download, never runPackages are fetched as plain files. No install scripts, no builds, no Play mode.
  2. Pattern scanFlags scripts downloaded and piped into a shell, hidden payloads, password and wallet theft, webhooks that send data out, reverse shells, miners, persistence, Roblox require(id) backdoors, and prompt injection in MCP tools.
  3. Real malware scannersWindows Defender, ClamAV, GuardDog, osv-scanner and modelscan, whichever you have installed.
  4. Human-style reviewClaude reads every flagged line and every entry point, then checks the author, ownership changes, typosquat names, and whether the package matches its source.
  5. Pinned installInstalls the exact commit, version, digest or asset ID that was scanned, never "latest".

Ratings

✅ CleanA real scanner ran and the review found nothing.
⚠️ ReviewA real risk with a legitimate reason. Needs a second yes.
❔ UnverifiedNo scanner ran, or the code couldn't be fully read.
⛔ BlockSteals data, hides code, or downloads and runs code. Never installs.

Honest limits: Vetted lowers the risk; it can't rule it out. Well-hidden or time-delayed malware can get past any scanner. Install only what you need.

Install

claude plugin marketplace add <user>/vetted
