/vetted:find

Describe what you need. You get 3 to 5 scanned options, one recommendation, and a pinned install once you say yes.

/vetted:report

A one-screen fact sheet on one tool or many: author, the license in plain words, activity, contents, install command and safety rating.

/vetted:update

Updates what you installed, scans only what changed, and warns you about bad news: archived, deprecated, sold to a new owner, or shutting down.

How the check works.

  1. Download, never runPackages arrive as plain files. No install scripts, no builds, no Play mode in Studio.
  2. Pattern scanCatches scripts downloaded and piped into a shell, hidden payloads, password and wallet theft, data sent out through webhooks, reverse shells, miners, Roblox require(id) backdoors and prompt injection in MCP tools.
  3. Real malware scannersWindows Defender, ClamAV, GuardDog, osv-scanner and modelscan, whichever you have installed.
  4. A careful readClaude reads every flagged line and every entry point, then checks the author, ownership changes and typosquat names.
  5. Pinned installThe exact commit, version, digest or asset ID that was scanned. Never "latest".
CleanA real malware scanner ran and the review found nothing.
ReviewA real risk with a legitimate reason. It needs a second yes.
UnverifiedNo scanner ran, or the code couldn't be fully read. Treated like Review.
BlockSteals data, hides code, or downloads and runs code. It never installs.

Honest limits: Vetted lowers the risk; it can't rule it out. Well-hidden or time-delayed malware can get past any scanner. Install only what you need.
