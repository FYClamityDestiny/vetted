Six commands.

Three for finding tools, three for looking after what you already have.

/vetted:find

Describe what you need. You get 3 to 5 scanned options, one recommendation, and a pinned install once you say yes.

/vetted:report

A one-screen fact sheet on one tool or many: author, the license in plain words, activity, contents, install command and safety rating.

/vetted:digest

What’s new and worth it in the topics you care about. Run it weekly on a schedule.

/vetted:update

Updates what you installed, scans only what changed, and warns you about bad news: archived, deprecated, sold to a new owner, or shutting down.

/vetted:uninstall

Removes a tool and what it left behind: config, containers, and data volumes (it asks first). Then tells you which keys to revoke.

/vetted:share

Used something and it was fine, or not? Share the result so the next person is protected too. Opt-in and public.

What we catch.

The patterns behind most real supply-chain attacks, checked on every scan.

  • Classic malware tricksDownloaded scripts piped into a shell, hidden payloads, reverse shells, miners, startup persistence, antivirus being switched off.
  • Data theftCode that reads SSH keys, browser passwords or crypto wallets, or sends data out through Discord or Telegram webhooks.
  • Risky setupsInstall-time scripts, shell access, bundled binaries, pickle model files, hidden instructions in MCP tools.
  • Roblox backdoorsRemote require(id), loadstring, and scripts hidden deep inside models.
  • Bad trust signalsBrand-new accounts, a change of owner, typosquat names, packages that don’t match their source, projects shutting down.
  • Known malware anywhere in the treeThe package and every dependency, checked against public malware and vulnerability lists.

How the check works.

  1. Download, never runPackages arrive as plain files. No install scripts, no builds, no Play mode in Studio.
  2. Pattern scanCatches scripts downloaded and piped into a shell, hidden payloads, password and wallet theft, data sent out through webhooks, reverse shells, miners, Roblox require(id) backdoors and prompt injection in MCP tools.
  3. Every dependencyThe whole dependency tree, resolved without installing, checked against known-malware and vulnerability lists.
  4. Real malware scannersWindows Defender, ClamAV, GuardDog, osv-scanner and modelscan, whichever you have installed.
  5. A careful readClaude reads every flagged line and every entry point, then checks the author, ownership changes and typosquat names.
  6. What it can doA capability profile: network, running programs, files, secrets. A new one in an update is a warning.
  7. Pinned installThe exact commit, version, digest or asset ID that was scanned. Never “latest”.
CleanA real malware scanner ran and the review found nothing.
ReviewA real risk with a legitimate reason. It needs a second yes.
UnverifiedNo scanner ran, or the code couldn’t be fully read. Treated like Review.
BlockSteals data, hides code, or downloads and runs code. It never installs.

Honest limits: Vetted lowers the risk; it can’t rule it out. Well-hidden or time-delayed malware can get past any scanner. Install only what you need.
